# HELL-1.0 / 1.1 / 1.1.1 → HELL-1.2 兼容性

这是规则对照，不是存档迁移承诺。旧战役、终局、种子和审计链均不修改。新版开新创世，旧版保持原封存代码结算。

## 证据范围

HELL-1.0对照来自已核实冻结规则与引擎，双方文件哈希与当时创世清单一致；此文只复述公开机制，不包含私密存档、目标分配或种子。核验用旧引擎SHA-256为 a01b0dc37d39237956f14961eeebb862f4cb6ba12c1721a023449a7fb472893b。

HELL-1.1-POLITICS已知增加非推进式人物谈话和政治交互；HELL-1.1.1涉及终局盟约期限修订。未获得完整冻结1.1/1.1.1源码的细项不推定与1.0完全相同，也不声称下面每一数值都经过三旧版逐字节等价验证。新版当前唯一结算依据为src/seven_kings/rules.py。

## 外交与合作逐项

| 类型 | HELL-1.0 | HELL-1.2 |
| --- | --- | --- |
| none | 无外交 | 保留 |
| bribe | 1–4金，信任+min(金额,3) | 信任增益上限改2；结算余额不足明确拒绝，不能造金 |
| propose | 通常信任≥2、丑闻≤3；和平目标有例外；失败仍付费 | 统一信任≥1、各≤2盟约；成功才收1金并转给对方，失败不收费 |
| threaten | 成功夺≤2金、影响+1、丑闻+1；失败威望−2；总是信任−2 | 成功影响+2、信任−2、紧张度+1，无夺金/丑闻；失败威望−2 |
| betray | 夺≤3金，影响+2、威望−3、丑闻+3、信任−5 | 无夺金/影响奖励；威望−2、丑闻+3、信任−3、资本清零、紧张度+3 |
| 普通盟约 | 上限2条，持续至成立轮+3 | 保留；政治支持仍有条件 |
| court/票约 | 1.0无独立字段 | 新增项目、援助、人情、续约、买票、共同提名，见玩法手册 |
| NPC主动谈判 | 旧版完整实现未在此做等价认证 | 新增先封存报价、双向参与费、接受/拒绝/还价、期限与真实合同 |
| talk | 1.1非推进式谈话 | 明确实现只读，不将台词视作数值承诺 |

新增合作资本、紧张度与合同机制使“盟友必定投我”不成立；长期合作会改变真实偏好和报价。NPC主动报价的正式合同在有效期内受保护，不会被随后普通NPC政治动作偷偷替换；玩家明确违约仍有后果。
