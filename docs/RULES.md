# HELL-1.2 中文玩法手册

## 目标与公开信息

玩家控制A，另外六家各有一个封存秘密目标。A的公开使命是终局至少两个有效盟约、丑闻≤2。初始帝国稳定12；每家有黄金、卫队、影响力、威望、情报、丑闻和王印。上限依次为30、18、20、16、12、10、5；资源不低于0。

每回合公报给出议案、世界事件、公开资源、A与各家的信任/政治资本/紧张度、盟约期限、来信和先行封存的AI计划承诺。隐藏目标和GM种子不在公报中。进行中分数只反映公开资源，秘密目标的12分奖励只在终局计入。

## 回合顺序

1. 生成公报并封存NPC计划；验证玩家组合预算。
2. 玩家议会/选举影响力及政治询价费用先扣；玩家主行动执行。
3. 六家NPC主行动（包括袭击）执行。
4. 玩家外交、NPC外交、来信回复、玩家政治行动、NPC政治行动执行。
5. 议会投票；赞成严格多于反对才通过，盟约一致投票积累合作资本。
6. 选举回合结算王印与票约；结算世界事件。
7. 各家支付1黄金维护费，不足则威望−1；清理到期盟约，检查硬失败/终局。

指令起始校验会计入征税所得，但政治交易仍检查实际余额。NPC先行袭击可能使稍后的贿赂失败；失败不能凭空生成黄金或信任。动作效果受资源上限影响。

## 主行动 action

| type | 成本 | 效果 |
| --- | --- | --- |
| tax | 0 | 黄金+5，威望−1 |
| reform | 2黄金 | 威望+2，稳定+1 |
| campaign | 3黄金 | 威望+1，影响力+2 |
| lobby | 3黄金 | 影响力+3 |
| muster | 3黄金 | 卫队+3 |
| spy | 1黄金 | 情报+3 |
| pass | 0 | 不执行主行动 |
| raid | 2黄金；卫队≥目标+3 | 指定B–G，最多抢3黄金；自身丑闻+3，稳定−1，与目标信任−4、紧张度+2 |
| sabotage | 3情报 | 指定B–G，目标影响力−3，自身丑闻+2，与目标信任−3、紧张度+2 |

示例：{"type":"raid","target":"B"}。不能攻击自己，允许目标是盟友，但关系受损，不自动解除盟约。秘密目标不会通过攻击接口返回。资源不足或门槛失败不能偷偷替换成另一种玩家动作。

## 外交 diplomacy

- none：不处理外交。
- bribe：目标B–G，amount 1–4黄金；实际成功付款才转账，信任增加 min(amount,2)。
- propose：建立盟约，支付1黄金给对方；双方盟约槽少于2且信任≥1。新盟约存续到当前回合+3（该回合结束后过期）。
- threaten：卫队≥目标+3时影响力+2，但信任−2、紧张度+1；失败威望−2。
- betray：解除已有盟约，丑闻+3、威望−2，信任−3、合作资本清零、紧张度+3。不能同回合背叛又与同一家合作。

## 政治 court：信任不等于无条件支持

政治目标必须是回合开头的盟友。关系的信任范围−5..5，合作资本0..10，紧张度0..8，拒绝计数0..8。信任达到上限后，真实合作仍可增加资本。政治行动通常不保证成功。

- joint_project：发起方2黄金、盟友1黄金；须信任≥2。双方威望+1，发起方影响力+1，稳定+1，信任+1，资本+2，紧张度−1。反复项目有真实成本、每回合行动占用与资本上限。
- aid：kind为gold转2黄金，或guards转1卫队。成功获得1人情（最多2），信任/资本+1，紧张度−1。
- request_aid：消耗1人情，盟友须保有至少3黄金或2卫队，取回2黄金或1卫队。
- renew：在盟约剩余≤1回合的窗口内，信任≥3，支付2黄金给盟友，期限延长至至少当前回合+3。
- request_backing：购买盟友对A的下一次选举支持；offer_gold 1–4，offer_influence 0–2，use_favor可选布尔。先收1影响力询价费。价值=3×金+2×影响+4×人情；门槛=max(1,候选偏好差+4−min(5,资本整除2)+min(4,紧张度))。
- whip_motion：同样先收1影响力；价值=2×金+2×影响+3×人情，门槛 max(1,3−资本整除2+紧张度)，成功令该盟友议会票与玩家一致。
- coalition：与盟友共同提名candidate为A–G；双方各付1金。对方对候选人的偏好差必须≤资本+2。合同绑定签约双方，不要求被提名人也是盟友；提名第三方不会把第三方变成合同义务人。

正式合同必须依赖有效签约盟约。每个投票人在同一选举最多保留一个有效承诺，普通后签承诺替换普通旧承诺；已接受的NPC主动报价合同在选举或盟约取消前受保护，不能被覆盖或重复付款。A可选择违约投票，但会丑闻+2、与签约方信任−2、紧张度+2。有效NPC承诺按合同投票。共同承诺的关系奖励只算一次，避免双方履约重复刷收益。

## NPC主动邀约与还价

公报offers是NPC计划的一部分，早于玩家行动封存。报价列出发起人、候选人、选举回合、有效期、双方资源交换及每个候选人的还价门槛。可以无需先发起court就回应。只可响应本回合实际收到的一个offer_id：

~~~json
{"offer_reply":{"offer_id":"复制公报中的真实ID","response":"accept"}}
~~~

将上述字段加入完整命令。明确拒绝用response为decline；忽略报价不自动计为拒绝。还价如下，数值必须符合报价中已经封存的门槛，NPC不会看完你的选择后改价：

~~~json
{"offer_reply":{"offer_id":"复制公报中的真实ID","response":"counter","candidate":"A","offer_gold":2,"offer_influence":1}}
~~~

每方支持门槛均为max(1,本人对候选偏好差+4−min(5,资本整除2)+min(4,紧张度))，在报价时封存。玩家报价价值3×金+2×影响需满足NPC门槛；NPC出价为min(4,玩家门槛除3向上取整)金，玩家仍可拒绝。接受或有效还价会收双方各1黄金参与费，再执行约定转账，续盟至选举回合并形成真实票约。候选人可以是A、NPC自己或第三方。过期、无效盟约或实际余额不足都会拒绝并记录原因。拒绝计数未饱和时每两次明确政治拒绝增加1紧张度；计数达到8后，继续每次拒绝都增加1紧张度，直到紧张度上限8。

旧reply字段accept/decline单独控制envoy的续约/资金请求；它与offer_reply不是同一字段。组合行动的总黄金和影响预算需要同时满足。

## 议会、王印、世界事件

玩家议会基础票重1，sway 0–2增加票重并花费等量影响力。NPC依据公开影响与其秘密目标判断；盟友只在接近中立时倾向跟随A，不是无条件服从。

王印选举在4/8/12/16/20回合举行。玩家candidate指定A–G，bid 0–3增加票重并花等量影响力。NPC可用影响力加权。平票依次比较候选威望、影响力、较低丑闻和家族字母序。获胜者王印+1、威望+2、黄金+2。票约是支持承诺，不能保证赢得选举。

公报逐回合直接显示完整议案/世界事件效果；随机性来自种子哈希，无运行时隐式随机。十类议案是赈济、征兵、学院、禁运、大赦、庆典、边防、共税、改革、弹劾。十类世界事件是丰收、旱灾、瘟疫、祥瑞、远洋商队、情报泄漏、改革风潮、边境侵袭、暴动、未遂政变。

## 终局与硬失败

最多20回合；稳定归零或A丑闻达到8会提前硬失败。第20回合还检查A威望≤0。最终分数=黄金+卫队+影响力+2×威望+情报+5×王印−3×丑闻+秘密目标完成奖励12。分数相同按家族字母序排列。

A普通胜利须无硬失败且总分第一。完全胜利还要求领先第二名至少22分、王印≥3、丑闻0、稳定≥7并完成A使命。第20回合结束才到期的盟约仍计入该次使命检查；早于20回合的到期盟约照常清理。NPC目标在终局揭示：王印≥2、卫队≥12、威望≥12、情报≥9且丑闻≤2、稳定≥8且丑闻≤1、黄金≥15，具体分配封存在GM档案中。

## 剧情与谈话

角色按家族身份、当回合议案、世界事件与公开关系作答。行动对白引用真实事件ID和演员，不把NPC结盟冒记为A的行为。talk的文本是咨询，不是自由文本规则引擎；说“给我黄金”不会绕过资源或合同约束。复现性依赖相同代码、种子、创世与命令序列。
