# 七王议会 / Seven Kings Council

Deterministic, auditable twenty-round grand-strategy game with seven houses.

> **Development status:** HELL-1.2 is under active development. Historical HELL-1.0 / 1.1 / 1.1.1 game outcomes are immutable and are **not** retroactively recalculated. New gameplay and test fixtures will land on a separate development branch for review.

Security and reproducibility: do not commit active-game GM secret seeds, unrevealed NPC objectives, or private game-state archives. Source code, synthetic fixtures, and the fixed, documented mechanics are appropriate for this public repository.
